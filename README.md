## SRB

Ovaj projekat rađen je na predmetu Analogna Integrisana Kola na Elektrotehničkom fakultetu Univerziteta u Beogradu. Ovaj kurs obrađuje osnove dizajniranja i projektovanja analognih kola gm/Id metodologijom u 65nm CMOS tehnologiji uz pomoć Cadance Virtuoso programskom alatu. 

Za projekat pravljen je LDO regulator po radu od B.Razavi koji se takodje nalazi u ovom direktorijumu. Licence možda nisu ispoštovane kačenjem ovog rada, ali nadajmo se da Razavi neće da me tuži. 

U dikretorijumu Cadance nalaze se source fajlovi napravljeni pomoću programskog alata Cadance Virtuoso u kom se nalazi kompletna komponenta.

U direktorijumu `python` nalaze se Python kodovi korišćeni za projektovanje ovakvog regulatora po `.mat` modelima iz direktorijuma `models`.

## ENG

This project was completed as part of the Analog Integrated Circuits course at the School of Electrical Engineering, University of Belgrade. The course covers the fundamentals of analog circuit design using the gm/Id methodology in 65nm CMOS technology with the help of Cadence Virtuoso software tool.

For the project, an LDO regulator was designed based on a paper by B. Razavi, which is also included in this directory. The licensing requirements may not have been fully respected by uploading this paper, but hopefully Razavi won't sue me for it.

The Cadence directory contains the source files created using Cadence Virtuoso, including the complete circuit design.

The `python` directory contains the Python scripts used to design this type of regulator based on the `.mat` models provided in the `models` directory.
